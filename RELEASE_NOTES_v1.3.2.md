# YBY Core v1.3.2 Release Notes

## Scope

YBY Core v1.3.2 is a metadata-only patch release.

It contains the same runtime capabilities as v1.3.1 and supersedes v1.3.1 as the deployable release candidate because v1.3.1 contained incorrect WordPress readme stable-tag metadata.

## Runtime behavior

No Lead, Case ID, Thank You, WhatsApp, Tracking, modal, CTA, API, email, or database behavior changed.

## Database

The database version remains 1.1.0.

## Release status

Dev deployment still requires validation PASS before installation.
