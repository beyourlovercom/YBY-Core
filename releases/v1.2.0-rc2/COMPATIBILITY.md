# Compatibility

RC2 remains compatible with the frozen v1.x public runtime API surface.

Preserved runtime objects:

- `window.YBYCoreConfig`
- `window.YBYProject`
- `window.YBYContent`
- `window.YBYTemplate`
- `window.YBYLead`
- `window.YBYTracking`
- `window.YBYThankYou`
- `window.YBYBrand`

No breaking REST contract changes were introduced in RC2.
