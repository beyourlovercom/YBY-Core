# Upgrade Guide

Upgrade from the governed v1.2.0 RC1 line to `YBY Core v1.2.0 RC2`.

Steps:

1. Back up the site and database.
2. Replace the previous plugin package with the RC2 ZIP.
3. Activate or refresh the plugin in WordPress.
4. Confirm lead submissions still produce the governed REST response.
5. Confirm the notification email uses the configured subject template and branding settings.
