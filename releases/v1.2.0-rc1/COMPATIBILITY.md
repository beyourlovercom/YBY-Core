# Compatibility

## Platform compatibility

- WordPress requires at least: `6.0`
- WordPress tested up to: `6.6`
- PHP requires at least: `7.4`

## Runtime compatibility

RC1 preserves the frozen v1.x public runtime line:

- `window.YBYCoreConfig`
- `window.YBYProject`
- `window.YBYContent`
- `window.YBYTemplate`
- `window.YBYLead`
- `window.YBYTracking`
- `window.YBYThankYou`
- `window.YBYPageProfile`

## Integration compatibility

- GTM installation remains external
- theme modifications remain external
- Bricks page implementation remains external
- website code remains owned by `ybyirrigationcom`

## Known release boundary

This RC1 is prepared for production verification, not direct production deployment.
