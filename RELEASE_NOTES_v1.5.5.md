# Andy Core v1.5.5 Release Notes

Release type: Stable updater canary
Plugin version: 1.5.5
Database version: 1.4.0

This release intentionally makes no business-runtime or database-schema change. Its purpose is to provide the first signed private GitHub Release that an installed Andy Core v1.5.4 instance can discover, verify, back up, install through WordPress native Update Now, and health-check end to end.

Release assets include the signed updater evidence required by v1.5.4: the package ZIP, SHA256.txt, update-metadata.json, and update-metadata.sig.
