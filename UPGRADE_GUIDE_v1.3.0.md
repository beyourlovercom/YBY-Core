# YBY Core v1.3.0 Upgrade Guide

1. Back up the existing production plugin, database, and YBY Core option snapshots.
2. Replace the plugin files with the exact `v1.3.0` release package.
3. Preserve production recipients, SMTP, CRM, and unrelated WordPress options.
4. Verify the plugin remains active and the database version remains `1.1.0`.
5. Verify the production Catalog, Thank You URL, Return URL, and YouTube ID use production-safe values.
