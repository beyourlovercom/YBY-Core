# Tracking Module

## Purpose

Provide safe frontend tracking helpers without installing GTM or Google tags.

## Current MVP Status

- public JS helper exists
- `window.YBYTracking` exists
- safe `dataLayer` push helpers exist
- Thank You Page tracking wrappers exist
- tracking payload can use page-level product interest and tracking group
- no GTM or Google Tag injection exists

## Future Roadmap

- more event wrappers
- internal validation for approved event names
- better debug visibility
