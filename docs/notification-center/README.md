# Notification Center

The YBY Core Notification Center is the abstraction layer for outbound lead notifications.

Current provider:

- Email

Email provider capabilities:

- configurable recipient lists
- configurable lead email subject templates
- email branding settings for company name, website, phone, WhatsApp, copyright, and logos
- safe HTML and AltBody generation

Planned future providers:

- CRM
- ERP
- AI
- Webhook
- Slack
- Teams
- Enterprise WeChat

This repository release only implements the Email provider. Future providers are intentionally not implemented yet.
