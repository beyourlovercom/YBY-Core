## 1. Implemented code (shadow-only, no Woo hooks)
- `includes/class-andy-commerce-m9-usd-rule-engine.php` — strict, pure USD-rule preview evaluator. Validates Currency OS V1 `mode=DEV_SHADOW_NO_PAYMENT`, base USD, supported currency and Woo zone 0/1/3/4/5. Rejects invalid/reused IDs, money fields, bad types/priority and unapproved active rules. Evaluates up to 100 independent eligible gift and fixed-amount discount rules. Shipping remains entirely owned by the selected native Woo zone; arbitrary free-shipping campaign inputs are explicitly rejected in M9. All awards remain OFF.
- **Qualification** uses `eligible_subtotal_usd_minor` from the already discount-reduced Currency OS ledger; excludes tax/shipping/noneligible products and gifts. All qualifying gifts can be listed but **never awarded**. Discounts choose **one** highest-benefit projection; tie by priority then rule ID. No automatic stacking. Recompute ordinary shipping policy using **further reduced qualifying USD subtotal**. For zone 1 HK, native no-threshold free method is NOT assumed present unless independently verified. `charge_waived=false` unconditionally, even if shadow qualification is true. Special $30/parcel and PILLOW $30/item fees never waived.
- `admin/views/marketing-m9-usd-multirule-lab.php` — protected Dev-only (`home_url` exact hostname and `manage_woocommerce`) GET-only simulation studio plus a separate, guarded M7 inactive-draft creation form. Five currency choices and five Woo zone choices; freely test gross, prior discounts, Gift USD threshold, first discount USD threshold/reward, second discount threshold/reward. Shows all independently evaluated rules, single projected discount and after-award free shipping qualification. Uses fixed **synthetic** historic FX fixtures **only**. Also maps compatible inactive USD `M7 Draft Studio` Spend & Save and free_gift records to preview-only rules (up to 40), no existing-draft edits. Compatible inactive USD Drafts may be created with a friendly M9 form that posts to the EXISTING M7 `andy_commerce_m7_save_draft` route, reusing exact nonce/capability/Dev-only guards and storing `active=false`. No new endpoint or database table. All mismatched/unsafe M7 drafts skipped.
- URL: `https://dev.beyourlover.com/wp-admin/admin.php?page=andy-commerce&tab=marketing-promotions&m9_preview=1` **after Dev deployment and safe readback**. Linked from existing Marketing Studio page. Currency OS lab adds a link to Marketing OS Multi-Rule; its former **single $99 figure is only a ledger demo**, no global setting.
- No automatic coupons, gifts, discounts or real shipping manipulation. No frontend Store API and no third-party ZIP required.
