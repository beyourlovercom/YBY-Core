# YBY Core v1.3.0 Release Notes

## Release Identity

- Product: `YBY Core`
- Release: `v1.3.0`
- Tag: `v1.3.0`
- Release type: stable

## Release Date

- `2026-07-22`

## Stable Version

- Plugin version: `1.3.0`

## Database Version

- Database version: `1.1.0`

## Major Capabilities

- reusable Inquiry component system
- Inquiry Field Registry and Inquiry Preset Registry foundations
- governed shortcode and modal runtime for Inquiry capture
- structured lead persistence with `custom_fields` support
- notification provider and email presentation support
- server-owned Site Profile identity
- configurable Brand Profile
- Brand Runtime for safe public presentation
- server-generated brand Case IDs
- Thank You runtime hydration and local tracking deduplication
- governed WhatsApp Message Template behavior
- deterministic Harness coverage for critical runtime paths

## Security Boundaries

- public Runtime exposes safe customer-facing configuration only
- REST ignores client brand, website, and Case ID
- customer-facing WhatsApp output excludes internal source and tracking fields
- recipients, SMTP values, and CRM webhook URL remain server-only
- `window.YBYThankYou.__testOnly` requires exact test mode and is hidden publicly
- only `case_id` may appear in the Thank You URL

## Upgrade Notes

- `v1.3.0` remains backward-compatible within the governed v1.x runtime line
- database upgrades to `1.1.0` through the normal plugin activation/update path
- no manual schema editing is required
- existing development-only validation records remain historical evidence and are not rewritten

## Configuration Notes

- site-specific WhatsApp copy belongs in Brand Runtime
- Project/Page legacy WhatsApp messages no longer control customer output
- production configuration must use production URLs, not development URLs
- YBY Irrigation production runtime values must preserve the intended production WhatsApp destination

## YBY Irrigation Production Checklist

- verify production SSH target resolves to `https://ybyirrigation.com`
- verify production Catalog URL uses the production domain
- verify Thank You URL is `/lp/thank-you-irrigation-solution/`
- verify Return URL is `/lp/irrigation-solution/`
- verify production YouTube ID is correct or intentionally empty
- preserve recipients, SMTP, CRM, and unrelated WordPress options
- back up plugin, database, and option snapshots before deployment
- run non-destructive production QA with analytics endpoints blocked

## Backward Compatibility

- frozen v1.x runtime APIs remain unchanged
- `POST /wp-json/yby/v1/leads` remains the governed public route
- database version remains `1.1.0`

## Known Non-Blocking Notes

- accepted development validation was completed on `dev.ybyirrigation.com`
- production deployment is performed after stable tag publication and QA
- Bottle deployment is not part of `v1.3.0`

## Rollback Reference

- production rollback must restore the previous verified production package and validated backups
- see `docs/deployment/M5B_DEV_DEPLOYMENT_AND_ROLLBACK.md` for accepted development rollback evidence
- see `ROLLBACK_GUIDE_v1.3.0.md` for stable release rollback steps

## Deferred v1.4 Work

- WhatsApp Conversation Widget
- floating launcher and teaser
- branded pre-chat window
- editable generated WhatsApp draft
- future transport abstraction
- no `v1.4.0` implementation is included in this release
