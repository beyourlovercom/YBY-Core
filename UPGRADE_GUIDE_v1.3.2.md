# YBY Core v1.3.2 Upgrade Guide

1. Back up the active YBY Core plugin.
2. Upgrade from the validated v1.3.0 package or from non-deployed v1.3.1 source.
3. Preserve existing Inquiry, Lead, Case ID, Thank You, WhatsApp, tracking, email, modal, CTA, and runtime configuration.
4. Confirm the database version remains 1.1.0.
5. Run Dev QA before Production installation.
