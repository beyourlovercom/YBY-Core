# Andy Core v1.5.5 Rollback Guide

Rollback target: latest compatible updater code backup

If the native v1.5.4 -> v1.5.5 update fails post-install health validation, the updater should restore the prior code backup automatically. Owner-triggered rollback remains available from Andy Core > Settings > Updates when a compatible backup exists.

Rollback is code-only. Database version remains 1.4.0.
