# YBY Core v1.3.2 Rollback Guide

1. Disable the v1.3.2 plugin package if Dev validation or smoke testing fails.
2. Restore the previously validated YBY Core v1.3.0 package until v1.3.2 completes Dev acceptance.
3. Keep existing Inquiry, Lead, Case ID, Thank You, WhatsApp, tracking, email, modal, CTA, and runtime configuration unchanged unless a validated rollback procedure requires otherwise.
4. Re-run Lead, Case ID, Thank You, WhatsApp, tracking, and notification smoke checks.

Do not treat v1.3.1 as an approved deployed rollback target unless deployment and acceptance evidence proves it was deployed and accepted.
