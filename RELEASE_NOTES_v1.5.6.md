# Andy Core v1.5.6 Release Notes

Release type: Stable updater-channel bootstrap
Plugin version: 1.5.6
Database version: 1.4.0

Andy Core 1.5.6 moves native update discovery and download to the public `beyourlovercom/andy-core-release` GitHub Releases channel. Installed WordPress sites no longer need a GitHub token, SSH access, or wp-config.php update credentials. Packages remain protected by SHA-256, pinned Ed25519 metadata signatures, strict ZIP validation, bounded pre-update code backup, post-install health validation, and rollback.

No database migration or business-runtime change is introduced.
